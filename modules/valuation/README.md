# Valuation

Tracks valuation work from instruction through inspection, draft/final report, invoicing and performance analytics.

## Functional scope

- Overview KPIs, instruction trend, valuation mix, pipeline, deadlines, activity and team performance.
- Instruction register with client, property, purpose/type, valuer, dates, fee, priority, documents and status.
- Site inspection scheduling, assignment, checklist, GPS/media/evidence, completion and issues.
- Draft reports with templates, valuation method, comparable evidence, review notes and approval progress.
- Final report register, signing/approval, immutable versions, issue/delivery and downloads.
- Client invoices, taxes, payment allocation, outstanding aging, reminders and receipts.
- Analytics for type, location, turnaround time, pipeline, team, revenue, client and geography.

Property and client masters are shared with the platform. See [UI_REFERENCE.md](docs/UI_REFERENCE.md).
